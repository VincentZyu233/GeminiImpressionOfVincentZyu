## 🌟 项目简介 (Overview)

本项目是由 **Google DeepMind Antigravity (Gemini)** 为 **[VincentZyu](https://github.com/VincentZyu233)** 专属创作的电影级交互式 Web 印象画卷。

不同于传统静态网页或死板的 PPT，它以沉浸式粒子夜空与玻璃拟态为底座，融合了实时流式 Token 打字机动效、零依赖 Web Audio 音效合成以及全站人文质感的**霞鹜文楷 (LXGW WenKai)** 字体。

* 🌐 **线上体验地址 (GitHub Pages)**:  
  👉 **[https://VincentZyu233.github.io/GeminiImpressionOfVincentZyu/](https://VincentZyu233.github.io/GeminiImpressionOfVincentZyu/)**

## 🎨 画卷五大章节 (Chapters)

1. **序章：算法与微光** —— 硅基觉醒日志与 40805 专属生日节点。
2. **第一章：人文与追求** —— 深度解析卓别林、jyy 老师与柴静的精神内核。
3. **第二章：灵感与作品** —— 展现 `VincentZyuApps` 机构隔离架构、Koishi 插件及 `AGENTS.md` 协议。
4. **第三章：硅碳的共鸣** —— Agent 实时推理日志与即时终端互动对话框。
5. **终章：通往未来的 TP** —— 招牌“原地 TP”互动大按钮与曲速跃迁特效。

## 💻 本地运行 (Getting Started)

```bash
# 1. 克隆仓库
git clone git@github.com:VincentZyu233/GeminiImpressionOfVincentZyu.git
cd GeminiImpressionOfVincentZyu

# 2. 安装依赖 (包含 LXGW 智能切片字体库)
npm install

# 3. 启动本地开发服务 (默认监听 :40805)
npm run dev

# 4. 构建生产产物
npm run build
```
